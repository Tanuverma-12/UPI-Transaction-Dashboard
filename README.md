# UPI Transaction Analysis Dashboard

##  Project Overview
This project focuses on analyzing UPI transaction data to understand transaction patterns, user behavior, payment trends, and key business insights.

An interactive dashboard was created using **Power BI** to visualize transaction volume, transaction amount, payment methods, locations, and time-based trends.

The objective of this project is to transform raw transaction data into meaningful insights that can help in decision-making.

---

##  Project Objectives

- Analyze UPI transaction trends and patterns
- Identify high-performing payment methods
- Understand transaction behavior across different locations
- Track transaction amount and transaction volume
- Create an interactive and user-friendly dashboard

---

##  Tools & Technologies Used

- **Power BI** – Dashboard creation and data visualization
- **Microsoft Excel** – Data cleaning and preprocessing
- **DAX** – Creating calculated measures and KPIs
- **Power Query** – Data transformation
- **Data Analysis Techniques** – Exploratory Data Analysis

---

##  Dataset Description

The dataset contains UPI transaction details including:

- Transaction ID
- Transaction Date
- Transaction Amount
- Payment Method
- Transaction Status
- Bank Details
- Location Information
- Customer/User Information

---

##  Dashboard Features

### Key Performance Indicators (KPIs)
- Total Transactions
- Total Transaction Amount
- Average Transaction Value
- Successful Transaction Rate

### Visualizations

- Transaction trends over time
- Payment method analysis
- Location-wise transaction analysis
- Transaction status distribution
- Amount-based analysis
- Interactive filters and slicers

---

##  Key Insights

- Identified transaction patterns based on time periods
- Analyzed popular payment methods
- Compared successful and failed transactions
- Observed customer transaction behavior
- Generated business insights using interactive visuals

---

##  How to Use This Project

1. Download the project files.
2. Open the `UPI Transacton.pbix` file using Microsoft Power BI Desktop.
3. Refresh the dataset if required.
4. Explore dashboard visuals using filters and slicers.
